# VPN Gate Client для Android

Клиент для бесплатных серверов [VPN Gate](https://www.vpngate.net/) на Kotlin и Jetpack Compose.

## Что умеет

- **Список серверов** из публичного API VPN Gate (`/api/iphone/`). Список кэшируется, поэтому без сети показывается последний сохранённый.
- **Обновление** кнопкой, жестом «потянуть вниз» или автоматически при запуске, если список старше 30 минут.
- **Проверка пинга**: замер до каждого сервера параллельно (TCP-рукопожатие, работает без root). Ход проверки виден, её можно остановить. Цвет показывает задержку: зелёный < 100 мс, жёлтый < 250 мс, красный — больше.
- **Фильтры**: по стране (чипы с флагами и числом серверов), поиск по стране, IP, имени или оператору, TCP/UDP, «только доступные».
- **Сортировка**: по рейтингу, пингу, скорости, нагрузке или стране.
- **Избранное** (★). Сервер сохраняется целиком вместе с конфигом и остаётся доступным, даже если пропал из свежего списка.
- **Кнопка «Лучший»** проверяет пинг у 30 лучших по рейтингу серверов (с учётом фильтров) и подключается к самому быстрому.
- **Карточка сервера**: скорость, сессии, аптайм, трафик, тип логов, оператор. Можно подключиться, проверить пинг, сохранить `.ovpn` или скопировать IP.
- **Статус подключения** в реальном времени, кнопка «Отключить».
- **Настройки**: адрес списка (для зеркал, если vpngate.net заблокирован), таймаут и параллельность пинга, автопинг, автообновление.
- Конфиги VPN Gate автоматически дорабатываются под OpenVPN 2.6 (`data-ciphers` для AES-128-CBC). Без этого новые клиенты часто не подключаются.

## Как устроено подключение

Туннель поднимает бесплатное приложение **OpenVPN for Android** (`de.blinkt.openvpn`, есть в Google Play и F-Droid). Наше приложение управляет им через его официальный AIDL-API: передаёт конфиг, получает статус и отключает.

Почему так:
- не нужно собирать нативный OpenVPN (NDK, OpenSSL и т.д.);
- файлы API OpenVPN for Android выведены из-под GPL, поэтому свой код можно не открывать;
- шифрованием занимается проверенная и поддерживаемая реализация.

При первом подключении появятся два окна: «Разрешить приложению управлять OpenVPN» и системный запрос на VPN. В обоих нужно нажать OK.

## Сборка

### Вариант 1: Android Studio
1. Откройте папку проекта (File → Open).
2. Дождитесь синхронизации Gradle.
3. Подключите телефон с включённой отладкой по USB и нажмите ▶ Run.

APK: Build → Build App Bundle(s) / APK(s) → Build APK(s).

### Вариант 2: без Android Studio, через GitHub
1. Создайте репозиторий на GitHub и загрузите туда проект.
2. Во вкладке **Actions** запустится сборка `Build APK`.
3. Когда она закончится, скачайте APK в разделе **Artifacts**.

### Вариант 3: командная строка (нужен Android SDK)
```
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

Release-сборка подписана debug-ключом, чтобы её можно было сразу установить. Перед публикацией в Google Play создайте свой ключ (Build → Generate Signed Bundle).

```

├── aidl/de/blinkt/openvpn/api/   AIDL-интерфейсы OpenVPN for Android
├── java/com/example/vpngateclient/
│   ├── data/VpnGateParser.kt     разбор CSV VPN Gate

│   ├── vpn/OvpnConfig.kt         разбор и доработка .ovpn
│   ├── vpn/OpenVpnController.kt  подключение/статус через AIDL
│   └── ui/                       экраны (Compose) и ViewModel
└── test/                         unit-тесты парсера
```

## Важно

- VPN Gate — академический эксперимент Университета Цукубы. Серверы держат волонтёры, они могут исчезать в любой момент, гарантий нет.
- VPN Gate **хранит логи подключений** (обычно 2 недели), а сами серверы принадлежат посторонним людям. Не передавайте через них ничего секретного без HTTPS.
- Если vpngate.net заблокирован, укажите в настройках адрес зеркала. Ещё один способ: подключитесь к серверу из сохранённого списка и обновите список уже через VPN.
- Перед распространением приложения проверьте, как законы вашей страны относятся к VPN.
